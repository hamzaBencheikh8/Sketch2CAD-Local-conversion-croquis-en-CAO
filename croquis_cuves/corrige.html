Enceintes sous pression — 15 croquis de test

Croquis volontairement hors échelle : seules les cotes écrites comptent. Comparez le résultat du programme (onglet 3D, encombrement, rapport) aux valeurs attendues.

Comment tester
  1. Lancez web.bat, déposez un croquis, cliquez Lancer (mode Local, puis refaites en mode API pour comparer).
  2. Comparez l'encombrement affiché et les perçages avec la carte du croquis ci-dessous.
  3. Pour tester une vraie photo : imprimez croquis_a_imprimer.pdf, photographiez une page avec votre téléphone.
  4. Tout d'un coup : python tools\bench_test_set.py croquis_test produit resultats.html.
